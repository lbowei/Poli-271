# 宏爵牛仔 · 出海方案（2026 年 11 月）

> 依据：TÜV 莱茵 amfori BSCI 社会责任审核照片记录（2025-12-12）+ 截至 2026-11-26 的公开政策信息。

## 0. 结论

**网站要做，广告也要投，也要让美国人下单。但第一步的对象要换：先找海外品牌/买手（B2B），暂时不直接卖给美国消费者（DTC）。**

| 你们的原计划 | 建议改成 |
|---|---|
| 建一个卖货的网站（Shopify 商城） | 建一个**工厂接单网站**（英文，给海外品牌看产能、起订量、合规） |
| 打 Facebook/Google 广告给美国消费者 | 打 **Google 搜索广告 + LinkedIn + 工厂内容短视频**，对象是找工厂的品牌主 |
| 美国消费者一单买 1 条 | 美国/欧洲/澳洲**品牌一单下 300–3,000 条**，反复返单 |

原因概括：同样的关税和广告预算，DTC 每卖一条大约**亏 $30–47**；B2B 每条**能赚 $2–3、没有库存和退货风险**，而且用得上你们真正的优势：工厂在新塘，小单能做，有 BSCI 审核。

## 2. 为什么「建站 + 投广告 + 美国消费者下单」不适合当第一步

### 2.1 账算不过来

假设：出厂成本 $12/条（约 ¥85），零售价 $59，退货率 25%（服装电商普遍 20–30%，牛仔裤因为尺码问题偏高），首单获客成本 $45（2026 年服装行业 $35–65 的中间值）。美国对中国产棉质牛仔裤的现行关税约 **36.6%**（见 2.2）。

| 每条（美元） | A. 自建站 + 中国直发小包 | B. 自有品牌 + 海运备货到美国仓 | C. B2B 给海外品牌做 OEM（FOB） |
|---|---|---|---|
| 收入（扣掉退货） | 44.25 | 44.25 | 出厂价 15.00 |
| 产品成本 | −12.00 | −9.60（退货 80% 可二次销售） | −12.00 |
| **关税** | **−21.59**（按**零售价** $59 计征） | −4.39（按进口申报价 $12 计征） | 0（买方是进口商，自付 $5.49） |
| 国际物流/清关 | −11.00 | −1.00 | 0（FOB 交货） |
| 美国仓储+派送+退货处理 | —（退货运回中国不划算，基本报废） | −12.00 | 0 |
| 支付手续费 | −2.07 | −2.07 | 0（T/T 电汇） |
| **广告前** | **−2.41** | **+15.19** | **+3.00** |
| 获客成本 | −45.00 | −45.00 | 约 −1.00（拿一个客户约花 $2,000，一年下 2,000 条） |
| **每条净贡献** | **≈ −$47** | **≈ −$30** | **≈ +$2** |

两个结论：

1. **关税按什么价征，差别很大。** de minimis（$800 以下小包免税）已经取消：中国在 2025-05-02 取消，所有国家在 2025-08-29 取消，2026-06 CBP 写进了法规。现在小包直发，关税按消费者付的零售价征；海运大货按出厂/进口申报价征。同样 36.6% 的税率，A 每条交 $21.59，B 只交 $4.39。**以后就算做 DTC，也不能从中国直发小包。**
2. **要让 DTC 跑通，得是品牌生意。** 按 B 模式算，零售价要到 **$89 以上**，同时获客成本压到 **$35 以下**，第一单才勉强不亏（+$1.79）。要卖到这个价，需要品牌、内容、评价、版型数据，这些要好几年和不少钱才能积累起来。

### 2.2 美国关税高，而且每隔几个月就变

现在美国对中国产棉质牛仔裤（HTS 6203.42 / 6204.62）的关税是叠加的：

| 层 | 税率 | 状态 |
|---|---|---|
| 基础关税 (MFN) | 16.6% | 长期 |
| 301 关税（2019 年清单 4A，服装） | 7.5% | 长期 |
| 301「强迫劳动」关税 | 12.5% | 2026-07-24 起 |
| IEEPA「芬太尼」/「对等」关税 | — | 2026-02-20 被最高法院判无效，已在退税 |
| 122 条款临时 10% | — | 2026-07-24 到期 |
| **合计** | **≈ 36.6%** | |

**昨天（2026-11-25）** USTR 又提出新的 301「产能过剩」关税：中国最高 **20%**，谈判不顺最高 **40%**（预计替代 12.5% 那一层）。2027-01-05 前征求意见，最早 2027 年初生效。如果实施，总税率会到 **约 44%，最高约 64%**。同一份提案里，越南最高 35%，孟加拉 18–20%，柬埔寨 18–25%，所以**换到东南亚生产也不一定更便宜**。

对 DTC 来说，关税每涨一次就直接吃掉利润（A 模式每条关税会从 $21.59 涨到 $26–38）。B2B 用 FOB 报价，**关税是美国买家的成本**，你们不直接承担政策风险。

### 2.3 UFLPA（新疆棉）是硬门槛

牛仔裤是棉制品，属于 CBP 重点执法的行业。2026-06 CBP 发布了新的强迫劳动执法指南；从 FY2025 到 FY2026 年 4 月，仅 UFLPA 一项就扣了 1.7 万多票货。**出口美国的牛仔裤，最好能提供棉花来源文件，从棉包到纱线到面料一路追溯。** 这件事做好了，反而是对美国品牌的卖点（见第 5 节）。欧盟强迫劳动产品禁令也会在 **2027-12-14** 开始适用。

### 2.4 运营门槛

- **广告账户**：中国主体投 Meta/Google 一般要走官方代理开户，封号很常见。
- **收款**：中国主体用不了 Shopify Payments，Stripe 通常要美国/香港公司。
- **售后**：要用英文客服、覆盖美国时区，还要有美国本地退货地址。
- **标签合规**：美国 FTC 要求纤维成分、原产国 "Made in China"、RN 号和洗涤标；做童装还有 CPSIA。
- **知识产权**：牛仔裤后袋弧形车线、红旗标是 Levi's 注册商标，常被起诉，自有款式要避开。

### 2.5 用不上你们的优势

DTC 拼的是品牌、内容、流量和美国本地运营，这些你们现在都没有；你们的优势（新塘供应链、小单快返、BSCI、自己有样衣间）在 DTC 里用不上。

## 3. 推荐路径：先做工厂出海（B2B），再做品牌出海

### 3.1 定位

> **"给新兴品牌做小批量牛仔裤的新塘工厂"**
> Small-batch denim manufacturer for emerging brands：每款 100–300 条起订，7–10 天出样，有 BSCI 审核，美国单可以提供棉花溯源文件。

这个定位能成立，是因为海外的小品牌（独立站品牌、设计师品牌、网红品牌）**在越南、孟加拉找不到愿意接 100–300 条小单的工厂**，那边的工厂起订量通常是每款上千条。这个缺口中国小厂最有条件补，2026 年也还是这样。

### 3.2 目标客户（按优先级）

1. **海外新兴 DTC 品牌 / Shopify 品牌**（美、英、欧、澳、加）：每款 100–500 条，看重品质、沟通和稳定，对价格没那么敏感。
2. **精品店连锁 / 零售商自有品牌 / 批发商**：英国、欧洲、澳洲、中东。
3. **网红 / 创作者联名、胶囊系列**：单量小，但传播效果好。
4. 牛仔工装 / 制服（可以后面再评估）。

### 3.3 市场优先级：不要只做美国

（中国产棉质牛仔裤一般贸易进口关税，近似值，以报关行核实为准）

| 市场 | 大致关税 | 判断 |
|---|---|---|
| **英国** | 12% | ⭐ 英语市场，独立品牌多，关税稳定 |
| **欧盟** | 12% | ⭐ BSCI 本来就是欧洲买家的标准，你们正好有。小包另收 €3/件（2026-07 起），只影响 DTC |
| **澳大利亚** | 0%（中澳自贸协定，要原产地证） | ⭐ 英语市场，关税最低，南半球季节相反可以错峰排产 |
| **美国** | ≈36.6%，2027 年可能 44%+ | 市场最大，但必须 FOB 报价、准备棉花溯源，政策变动快 |
| 加拿大 | 约 17–18% | 英语市场，风格接近美国 |
| 中东 GCC | 5% | 以批发商为主 |

做法：**美国当成市场之一，不要当成全部。** 网站和广告同时覆盖美、英、澳、欧。

### 3.4 获客渠道（这就是你们要投的「广告」）

| 渠道 | 做法 | 预算 |
|---|---|---|
| **英文工厂官网 + Google 搜索广告** | 投 B2B 关键词，比如 "low MOQ jeans manufacturer"、"private label denim manufacturer"、"custom jeans manufacturer"。转化目标是询盘/打样，不是下单 | 每月 $800–1,500 |
| **短视频（TikTok / Instagram / YouTube Shorts）** | 拍工厂幕后：裁床、洗水效果、做一条牛仔裤的全过程。这类内容自然流量很好，经常能带来小品牌的询盘 | 主要是人力，每周 3–5 条 |
| **LinkedIn 主动开发** | 找服装品牌创始人和采购，每天 20 个人，附上能力介绍 | 人力为主 |
| **阿里巴巴国际站**（可选） | 新塘同行很多都在上面，询盘量大但竞争激烈 | 每年数万元起，按实际报价 |
| **广交会**（就在广州） | 成本最低的面对面获客方式 | 低 |
| 行业展（第二阶段） | Kingpins（牛仔专业展）、Sourcing at MAGIC（拉斯维加斯） | 较高，先去看展 |
| 跨境平台供货（SHEIN / Temu / TikTok 全托管） | 可以填产能、回现金流，但利润薄、规则严 | 当补充，不当主业 |

**粗算漏斗（假设，要实测）**：每月 $1,500 广告 → 约 400 次点击 → 3–5% 留询盘 = 12–20 个询盘 → 20% 打样 = 3–4 个 → 一半下首单，**每月 1–2 个新客户，首单 $5,000–20,000**，以后会返单。对比一下：同样 $1,500 投 DTC，大约换来 33 个首单消费者，每人买 1 条。

### 3.5 接单规则

- **报价**：默认 FOB 深圳/广州。美国客户想要 DDP（含税到门）的话，找货代合作报价，关税另列，**不要把关税包进单价里**。
- **付款**：30% 定金，70% 出货前付清（T/T）。样衣费预收，大货下单时抵扣。新客户不做账期。
- **保密**：可以和客户签 NDA，不把客户款式卖给别人。这对品牌客户很重要。

## 5. 出海前要补的功课（客户会查）

### 5.1 BSCI 不符合项整改（海外买家会要审核报告）

| 问题 | 怎么改 | 时间/成本 |
|---|---|---|
| 车缝机缺护针、护罩 (PA 7.17) | 全部机器补装，拍整改前后对比照 | 1 周，几千元 |
| 厕所没有纸、洗手液 (PA 7.22) | 长期配备，指定专人检查 | 马上，几乎没成本 |
| 加班超时 (PA 6.2) | 排产不要超过实际产能，提高效率（吊挂、流水线平衡），旺季增加临时工；目标先压到每周 ≤60 小时 | 1–3 个月 |
| 社保覆盖不足 (PA 5.5) | 分批补缴，先覆盖骨干和长期工，给出时间表 | 全部补齐约 ¥39 万/年，可以分 2–3 年 |

改完申请复审，争取提高评级。**评级会直接影响欧洲客户的准入。** 你们这次拿的是 A–E 哪一级？

### 5.2 美国单的棉花溯源文件包

1. 和 2–3 家面料厂说好，美国单用**非新疆棉**（美棉、澳棉、巴西棉），要求对方提供**棉包 → 纱厂 → 布厂 → 你们**的发票、装箱单、原产地证。
2. 每个美国订单整理一份溯源文件（模板做一次，以后复用）。
3. 需要时可以做棉花同位素检测，作为额外证明。
4. 网站和报价单上写明 "UFLPA documentation available"。美国品牌很在乎这一点，很多同行做不到。

### 5.3 其他准备

- **英文外贸业务/跟单**：这是最关键的招聘，广州月薪约 ¥6,000–12,000 加提成。要求 24 小时内回询盘，最好能覆盖美国时区。团队里如果有人在美国，可以负责美国时段沟通、看展和见客户（先确认签证身份允许做这份工作）。
- **企业邮箱**：用 Google Workspace 自己域名的邮箱，别用 QQ、163。另外开 WhatsApp Business。
- **能力说明书（PDF）**：主打款式、面料、洗水效果卡、起订量、交期、价格区间（分基础 / 中档 / 高档三档）。
- **10–15 款样衣**：用来拍照、拍视频、给客户寄样。
- **洗水合作厂**：确认对方环保合规、有排污许可，客户问起时能说清楚。
- **认证（可选）**：面料端的 OEKO-TEX Standard 100 很常被问到；做环保系列可以加 GRS/OCS。先不用一次全做。

## 7. 什么时候、怎么做自有品牌 DTC

DTC 不是不能做，但要满足这些条件再做：

1. 有 **5 个以上稳定返单的 B2B 客户**，确认版型、洗水、品控都过关。
2. 选好一个**细分市场**，比如女款高腰弹力、高个/小个专门裤长、大码、男款运动版型、牛仔工装。这些地方大牌照顾不到，工厂的版型能力又最有用。
3. 走 **B 模式**：设立美国公司做进口商，海运备货到美国海外仓（FBA 或第三方仓），**不从中国直发小包**。
4. **先上已经有需求的平台**（Amazon、TikTok Shop），再做自己的 Shopify 独立站。
5. **设好止损线**：测试预算 $5,000–10,000。第一单获客成本高于首单毛利的一半，或者退货率高于 20%，就停下来复盘。

**现在就能验证你们想法的最便宜办法**：花 $1,000–2,000 做一个英文落地页，跑预售/等待名单广告，测一下美国消费者的真实点击成本和留资成本，**不备货**。数据好就进入第 7 节的流程；数据不好，你们只花了 ¥1 万左右就知道了答案。
